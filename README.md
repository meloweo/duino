# Jeu d'obstacles – Arduino UNO R4 WiFi

Mon tout premier projet Arduino : un petit jeu d'obstacles à base de boutons physiques et d'un écran LCD 16x2.

**Projet en cours** – le jeu n'est pas terminé, le code évolue encore.

## Principe du jeu

Le joueur doit éviter des obstacles qui arrivent sur l'écran, en utilisant des boutons physique. 
Le jouer doit faire le temps le plus long a chaque partie. Lorsque le joueur perd, la partie s'arrete et "GAME OVER" est affichée ainsi que le temps de partie. 
Si le jouer souhaite rejouer, il appuie deux fois sur le bouton.

## Matériel

- Arduino UNO R4 WiFi
- Écran LCD 16x2
- Boutons poussoirs
- Câbles, breadboard.

## Installation

1. Installer l'[Arduino IDE](https://www.arduino.cc/en/software)
2. Ajouter la carte Arduino UNO R4 WiFi via le gestionnaire de cartes
3. Installer la bibliothèque `LiquidCrystal` si besoin
4. Ouvrir le fichier `.ino` du projet
5. Brancher la carte, la sélectionner, puis téléverser.
